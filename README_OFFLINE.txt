========================================================================
🏆 VISUAL BULK CERTIFICATE GENERATOR - OFFLINE EDITION
========================================================================

This package contains everything needed to generate bulk certificates
100% OFFLINE without requiring an active internet connection.

------------------------------------------------------------------------
OPTION 1: ANDROID MOBILE & TABLET (No PC Needed)
------------------------------------------------------------------------
1. Install "Certificate-Generator.apk" on any Android phone or tablet.
   (If prompted, toggle "Allow install from unknown apps").
2. Open the "Certificate Generator" app.
3. Select your Certificate Template image and Student Excel file.
4. Auto-place or drag fields, preview live, and tap "Generate Certificates".
5. All certificates are saved as a ZIP archive directly to your Downloads!

------------------------------------------------------------------------
OPTION 2: INSTANT BROWSER APP (Zero Installation / No Python Needed)
------------------------------------------------------------------------
1. Double-click "Open Offline App (No Python Needed).bat"
   (or directly open "static/index.html" in Chrome, Edge, or Firefox).
2. The interactive visual canvas runs 100% offline in your browser.
3. Load templates and Excel sheets, position placeholders, and export ZIP.

------------------------------------------------------------------------
OPTION 3: WINDOWS DESKTOP APP (Python Tkinter GUI)
------------------------------------------------------------------------
1. Ensure Python 3 is installed.
2. Double-click "Launch Certificate Generator.bat".
3. The native high-performance desktop editor opens with 300 DPI PDF export.

------------------------------------------------------------------------
OPTION 4: LOCAL WEB SERVER (Python FastAPI)
------------------------------------------------------------------------
1. Double-click "Launch in Browser.bat".
2. Starts the local server and opens http://localhost:8000.

------------------------------------------------------------------------
ALL REQUESTED FORMATTING INCLUDED:
------------------------------------------------------------------------
✓ No decimals on Register Numbers & Certificate Numbers (e.g. 953321104018).
✓ 100% Attendance & Percentage formatting (e.g. 1 -> 100%).
✓ Smart Two-Line Wrapping for long project titles
  (e.g. "PLC-BASED SMART MANUFACTURING CONVEYOR" -> 2 balanced lines).
========================================================================
